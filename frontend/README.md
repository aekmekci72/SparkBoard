# SparkBoard

**SparkBoard** is a personal project and task management workspace built to help users organize their work into projects and track tasks from creation through completion. Tasks can be subsections of larger projects.

The application includes authentication, project management, task management, task filtering, task status tracking, and a dashboard-style workspace.

---

## Features

### Authentication

- Email and password sign up and login
- Google authentication
- Protected application routes
- Logout functionality
- User profile information displayed in the workspace

### Projects

- Create projects
- View projects from the workspace
- Project-specific task organization
- Project task statistics displayed in the sidebar

### Tasks

- Create tasks
- Assign tasks to projects
- Set task priority
- Set task status
- Add descriptions and due dates
- Mark tasks as completed
- Edit and delete tasks
- Search and filter tasks

### Dashboard

- Overview of project and task activity
- Task statistics
- Organized workspace layout
- Responsive interface for different screen sizes
